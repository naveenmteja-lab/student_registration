# Wonders Academy Student Registration

A responsive student registration form built with React and Vite. Students can
enter personal details, select a course and study preferences, and receive an
on-screen confirmation after submitting the form.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

Form submissions currently display a confirmation in the browser; connect a
backend service to store applications or contact students.
